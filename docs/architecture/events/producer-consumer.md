# Producer + Consumer Groups (centralized abstractions; delivery = at-least-once)

EventPublisher (infra, sole Kafka client owner): `publish(env)` / `publishBatch()` — validates envelope, routes type→topic, sets key=headers(corrId,causationId,version), serializes JSON, retries transient publish ≤3 (exp+jitter), surfaces failure to outbox (stays PENDING). Domain never touches Kafka client.
Groups (one reason each): notify-worker (notification.* + order/payment events → mail; 2 inst, manual-offset after inbox-tx); search-indexer (catalog/search → index upserts; 2 inst, version-gated); analytics-processor (order/payment/inventory/user → warehouse batch; 1–2 inst, at-least-once ok); order-event-handler (payment.* → order transitions; 2 inst, tx inbox+biz); inventory-event-handler (order.* → projections/alerts; 1 inst); audit-processor (all → auditLogs append; 1 inst). Offset: commit only after inbox-PROCESSED tx; restart → redeliver → dedupe (safe). Scaling: add instances ≤ partitions; lag>1k → scale + alert; rebalance drains in-flight first.
