# Ops LLD (adapters + observability + config + testing)

Adapters (domain depends on iface only): MailPort{send}→NodemailerSMTP/Mailpit-dev; PayPort→Stripe-like adapter; ShipPort→carrier adapter; StorePort→S3 presigned; SearchPort→Atlas query; AnalyticsPort→Kafka. Vendors injected in infrastructure; unit-test via fakes.
Instrumentation points: middleware (req log+latency+corrId), AppService (use-case spans+domain events), Repo (DB latency+slow-query), producer/consumer (publish/lag/retry/DLQ), adapters (ext latency+failures). Metrics: rps/err/p50-99/DB/Redis/lag/consumer/429/auth/pay/checkout/OTP. Audit: money+admin+RMA actions append-only. Security events: reuse-detect, sig-fail, throttle-spike.
Config: env validated at boot (fail-fast schema); secrets via manager (never code); flags/config cached 5m. Testing: unit (domain+policies+machines, fakes); integration (repos vs Atlas-memory, Redis/Kafka testcontainers); API (Supertest per module); contract (OpenAPI diff); E2E (register→refund); security (authZ matrix, limits, webhook-sig); perf (k6 checkout/pay). Mock vendors, never money logic.
File map (design only): `src/modules/{auth,users,catalog,pricing,cart,checkout,inventory,orders,payments,shipping,returns,reviews,notify,admin,audit}/…` + `src/shared/{kernel,errors,config,observability}` + `src/infra/{mongo,redis,kafka,outbox-publisher,inbox-dispatcher,mail,pay,ship,store}`. Sequence: config→DB/kernel→errors/obs→security/limits→auth/users→catalog→cart→inventory→checkout→orders→payments→outbox/inbox→notify→rest.
