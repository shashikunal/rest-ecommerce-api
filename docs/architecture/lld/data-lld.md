# Data + DTO/Validation + Errors + Concurrency + Idempotency LLD

Collections (purpose → shape/index/tx): users{email unique, pwHash, roles, tokenVer, status} idx email; sessions{userId, familyId, tokenHash, sid, exp, revoked} idx userId+fam, TTL exp; products{slug unique, status, attrs, media[]} text+{cat,price}; productVariants{sku unique, productId, attrs} idx sku/product; categories/brands{name unique, slug}; inventory{skuId unique, avail/res/sold, ver} cond-inc, tx checkout; carts{userId unique, lines, ver, exp} TTL 30d; wishlists{userId unique}; addresses{userId, lines}; orders{userId, items-snap, totals-snap, addr-snap, status, ver, idemKey unique} idx user+created, {status+created}; payments{orderId, attemptNo, amount, status, providerRef, idemKey unique}; refunds{rmaId unique, orderId, amount, status}; shipments{orderId, tracking}; returns{rmaId unique, state}; coupons{code unique, caps} atomic-inc; promotions; reviews{(product,user) unique}; notifications{eventId unique, to, template, status}; notificationPreferences{userId unique}; auditLogs append-only idx {actor+ts}; outboxEvents{status+created}; inboxEvents{eventId+consumer unique}; idempotencyRecords{key unique} TTL 90d money.
DTO rule: Zod at edge (body/params/query/headers incl. paging `limit≤50`, sort allowlist); AppService maps DTO→domain; responses via mappers (never raw docs; strip hashes/tokens). Errors: domain E_* → HTTP (validation 400, auth 401 generic, forbid 403, missing 404, conflict 409, limited 429+Retry-After, dep-fail 503, else 500) shape `{code,message,details?,requestId,correlationId}`; no stacks/secrets/DB internals.
Concurrency/idempotency per §04 + commerce: reserve cond-inc; coupon atomic; order `expectedVersion`; webhook version-guard; inbox dedupe; release idem-keyed; idem `{key uuid, scope, reqHash, resp, status}` Redis 24h + Mongo 90d (money); hash-mismatch →422.
