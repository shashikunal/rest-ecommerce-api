# UX Index + Principles + IA + Screen Inventory (Phase 7 — design only, no frontend code)

Principles: reflect backend truth (state machines, sync/async, authZ) over decoration; mobile-first responsive; accessibility-first (keyboard, focus, semantics, non-color status); progressive disclosure; fast feedback with skeletons; explicit checkout/payment states; never show raw backend errors; never weaken security (no token/OTP exposure).
IA — Customer: Home → Categories/Search → Product → Cart/Wishlist → Checkout → Orders → Account(Profile/Addresses/Sessions/Notifications/Security) → Support. Admin: Dashboard → Orders/Payments/Returns/Refunds → Products/Variants/Categories/Brands/Inventory → Customers/Coupons/Promotions/Reviews → Notifications/Audit/Analytics/Settings. Guest ⊂ Customer minus account-gated actions (cart allowed per architecture; checkout requires auth).
Inventory: Public(13): Home, Listing, Search, Product, Category, Brand, Cart, Login, Register, Forgot, Reset, OTP-verify, Email-verify. Customer(17): dashboard, profile, security, sessions, addresses, wishlist, cart, checkout, payment, orders, order-detail, cancel, return-request, return-detail, refund-status, reviews, notifications+prefs. Admin(19): dashboard, products, product-editor, variants, categories, brands, inventory, orders, order-detail, payments, refunds, returns, customers, coupons, promotions, reviews-queue, notifications, audit-logs, analytics, settings. (Counts overlap shared screens; full per-screen spec in customer/checkout/auth/admin files.)
