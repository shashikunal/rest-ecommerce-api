# Customer Screens (layout detail per §8 standard; states summarized, full matrix in states.md)

Home: header(logo/search/account/cart) → hero → categories → featured/promos → recommendations → recently-viewed → footer. Skeletons per section; failed section → inline retry (never blocks page). APIs: GET products/search/promos.
Listing: breadcrumb + title + count; desktop sidebar filters (category/brand/price/rating), mobile bottom-sheet filter + sort drawer; cards (image/price/rating/stock-badge/wishlist-heart); cursor pagination ("Load more", no infinite-scroll default). Sort allowlist mirrors API.
Search: input + debounced autocomplete (products + recent local) + suggestions; results = listing layout; no-results → query echo + tips + top-categories; stale-index note when `indexedAt` lags (>60s banner "Fresh products may appear shortly").
Product: gallery + title + rating + price/discount + variant pills (SKU shown) + stock state (IN_STOCK/LOW/OUT) + qty stepper + Add-to-Cart + wishlist + delivery estimate + description/specs/reviews/related. SKU-unavailable → disabled selector + "Notify me" (prefs-gated); unpublished → 404 page; price/inv changed since view → banner "Updated while viewing — review" + refreshed totals (never silent).
Cart: lines (image/name/variant/qty-stepper/price/line-total/remove) + coupon field + totals (subtotal/discount/tax/shipping/total) + checkout CTA. Line flags: UNAVAILABLE / QTY_CAPPED / PRICE_CHANGED (old→new shown) / COUPON_EXPIRED; empty → illustration + "Browse products" CTA; expired session → login nudge preserving cart (merge on login per architecture).
Orders: list (filter status/date, search orderNo; cards desktop-tablet / stacked cards mobile; cursor pages) + detail (timeline per state machine, items snapshot, price/payment/shipment/address, actions gated by state: Cancel only CREATED/PENDING, Return only DELIVERED≤30d). All actions map to Phase 6 endpoints; impossible actions never rendered.
