# Auth + OTP + Sessions + Account

Login: email+password (+show/hide), generic "Invalid credentials" (no existence leak), loading→disabled button, 429 lockout message with countdown, success → redirect-to-intent (preserved deep link). Register: email/password-strength-meter/confirm + names; 409 → "Account exists — log in" link. Forgot → "If an account exists, a reset link was sent" (always); Reset: new-password + confirm, single-use token, expired → re-request link. Change-password (authed): current+new, success revokes others + mail notice.
OTP: 6-box accessible input (autocomplete=one-time-code, paste support), 60s resend countdown, states: invalid (attempts-left) / expired (re-request) / locked-5-tries (cooldown + support) — all generic re: account existence. Email-verify: same component, success → account badge.
Sessions screen: current badge + others (device/UA/IP/last-active) + Revoke + Revoke-all (confirm modal); revoked-elsewhere → banner "Signed out — please log in" preserving form drafts where feasible. Token expiry: silent refresh; refresh-fail → login redirect with return-to. Account hub: tabs Profile/Security/Sessions/Addresses/Notifications/Orders; security = password + 2-state verification + active sessions; addresses CRUD + default star; notifications = center (unread dot, read-all) + prefs toggles (order/shipment/marketing per channel; transactional always-on noted).
