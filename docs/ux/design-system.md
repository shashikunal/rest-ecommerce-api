# Design System + Components + Tokens + Forms + Accessibility + Responsive + Performance

Primitives (documented, not implemented): type scale (12/14/16/20/24/32) · spacing 4-base · radius 8/12 · shadows sm/md · breakpoints 360/768/1024/1440 · sizes sm/md/lg · motion 150/250ms + `prefers-reduced-motion` kill-switch.
Inventory: Layout(Header/Footer/Sidebar/PageContainer) · Nav(Breadcrumb/Tabs/Pagination/MobileNav) · Forms(Input/Select/Checkbox/Radio/Password/OTP/AddressForm, all labeled + error-slots) · Commerce(ProductCard/PriceDisplay/CartItem/OrderCard/OrderTimeline/Rating/StockBadge) · Feedback(Toast/Alert/Modal/Drawer/Skeleton/Empty/Error/Badge). Toast=light ack (3s) · inline=form/resource errors · modal=decisions/confirms (focus-trap, Esc, return-focus) · full-page=unavailable resource. Confirmations only for destructive (delete/archive/cancel/revoke/reject/inv-adjust); never for add-to-cart/save-draft.
Forms spec each (register/login/OTP/address/checkout/coupon/review/product/inv-adjust/return/refund): fields + required + labels/help + Zod-mirrored client hints (server authoritative) + disabled/submitting/success states. Offline: banner + preserved inputs + queued-safe retry (idem endpoints only); no offline-first.
A11y: keyboard-reachable everything (visible focus), semantic landmarks/headings, labels+`aria-describedby` errors, status via text+icon (never color-only), contrast AA, live-regions for toasts/timeline updates, modal/drawer focus management, OTP `inputmode=numeric`. Perf: route-lazy, responsive images (srcset, CDN, lazy-below-fold), skeletons, cursor pages, no blocking third-parties; telemetry later: page-load, API-fail, checkout-abandon, pay-fail, search-fail (never PII/secrets in events).
