# Admin + Webhooks + Internal (strict authZ; no raw CRUD)

Admin (all `admin`, 60/m, audited; staff/support subsets per authorization.md): products CRUD + `POST /products/{id}/publish|unpublish|archive` (no raw status PATCH) · variants `POST|PATCH|DELETE /products/{id}/variants…` (sku unique →409) · categories/brands CRUD (slug unique) · inventory `GET /inventory?sku=` + `POST /inventory/adjust {sku,delta,reason}` (never direct qty set) · orders `GET /admin/orders|/{id}` + `POST /{id}/transition {action: confirm|ship|deliver}` (version-guarded) + cancel · payments `GET` + `POST /refunds {orderId|paymentId,amount?,reason}` (Idempotency-Key required, amount-cap 422) · returns `POST /returns/{id}/approve|reject|complete` · coupons/promos CRUD (code unique; usage read-only) · reviews `POST /reviews/{id}/approve|reject` · users `GET /admin/users|/{id}` + `POST /{id}/lock|unlock` (no password/hash exposure) · audit `GET /admin/audit-logs` (cursor, filter action/actor) · analytics `GET /admin/analytics/summary` (precomputed, not live aggs).
Webhooks (no JWT; HMAC `X-Provider-Signature` + timestamp ±5m + 100/m/provider + idem by providerEventId): `POST /webhooks/payment/{provider}` → 200 `{received:true}` always (even dup → dedupe silently; invalid sig →401, no body detail). Provider payloads isolated per-provider schema; server re-fetches payment state (never trusts payload).
Internal (system role / mTLS note for Phase 8): worker status endpoints + outbox/inbox health — never public; no Kafka ops over REST.
