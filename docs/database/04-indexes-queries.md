# 04 Indexes + Query Patterns + Pagination

Index catalog (name · keys · opts · serves · cost): users `uq_emailNorm` {emailNormalized:1} unique (login; low write cost); sessions `ix_user` {userId:1,createdAt:-1} (list) + `ttl_exp` {expiresAt:1} TTL + tokenHash via `_id`-lookup pattern (store tokenHash→session _id map? design: index {tokenHash:1} sparse unique, revoke lookup; small); products `uq_slug` unique + `ix_cat_price` {categoryId:1,price:1} + `txt_search` text(name,desc) (browse/search; moderate); variants `uq_sku` unique + `ix_product` {productId:1}; categories `uq_slug`; brands `uq_slug`; carts `uq_user` {userId:1} unique; addresses `ix_user` {userId:1}; inventory `uq_sku` + version-guard (no extra); reservations `ix_order` {orderId:1} + `ix_sku_active` {skuId:1,status:1} partial active + `ix_exp` {expiresAt:1}; orders `uq_orderNo` + `uq_idem` + `ix_user_created` {userId:1,createdAt:-1} + `ix_status_created` {status:1,createdAt:1}; payments `uq_idem` + `uq_providerRef` sparse + `ix_order` {orderId:1}; webhooks `uq_provider_event` {provider:1,providerEventId:1} unique; refunds `uq_rma` + `uq_idem`; returns `uq_rma`; coupons `uq_code` + {status:1,validTo:1}; promos {status:1,from:1}; reviews `uq_prod_user` + `ix_prod_mod` {productId:1,status:1,createdAt:-1}; notifications `ix_user_created` + `ttl_created` 90d TTL; prefs `uq_user`; audit `ix_actor_ts` {actor.id:1,at:-1} (no TTL; archive 2y); outbox `ix_claim` {status:1,nextRetryAt:1} + `uq_event`; inbox `uq_consumer_event` {consumer:1,eventId:1} unique; idem `uq_key` + TTL.
NOT created: low-selectivity status-only indexes, per-field indexes without queries, `skip`-friendly assumptions, multi-text indexes.
Queries (filter→sort→index→page→consistency): login `{emailNormalized}` → uq (strong); session-by-hash (strong); product-by-slug (eventual-ok cached); list-by-category `{categoryId,status,price$gte/lte}` sort price + `_id` tiebreak → ix_cat_price, cursor `{price,_id}` (strong-not-required); search `$text` + filters (eventual); cart-by-user (moderate); reserve `skuId + available>=qty + version` atomic (strong); orders-by-user cursor (strong); outbox-claim `status=PENDING,nextRetryAt<=now` (strong); inbox-check (strong).
Pagination: cursor `{sortKey,_id}` opaque base64 everywhere high-volume; offset only small admin lists (≤200). No large skip; max limit 50.
